# ESQ — конфигураторы с подбором оборудования по ТЗ (ИИ)

Версия конфигураторов ООО «Элком» (ВВ ПЧ ESQ F ME800 / ME800-R и ВВ УПП ESQ F HVS) **вместе с подбором по ТЗ
с помощью ИИ**. Основной конфигуратор без этой функции — в репозитории `pufuna/esq-configurator`.

## Что здесь сверх основного конфигуратора

- `tz.html`, `tz.js` — разбор технического задания: загрузка ТЗ (PDF, DOCX, XLSX), распознавание требований
  облачной функцией с ИИ, проверка по правилам, листы соответствия и несоответствий в Word, переход в конфигуратор
  с подобранной моделью. Вход — значок «©» в подвале конфигуратора ПЧ или УПП, или прямо `tz.html` (`tz.html?p=upp` — УПП).
- Конфигураторы принимают параметры из разбора ТЗ: `configurator_vv_pch.html?from=tz&…`, `vv_upp.html?from=tz&…`
  (подбирается наименьшая модель по мощности и току, сверху — плашка «Конфигурация из разбора ТЗ»).
- `assets/vendor/jszip.min.js` — чтение DOCX/XLSX на странице ТЗ.
- Облачная функция разбора ТЗ: `https://functions.yandexcloud.net/d4eplvhu1pvut5be24vd`
  (`FUNCTION_URL` в `tz.js`; её код в этом репозитории не хранится).

Всё остальное (ТКП, реестр, чертежи, расчёт экономии, инструкция по внедрению в `deploy/`) — как в основном
конфигураторе на момент разделения. Изменения основного конфигуратора сюда сами не попадают.
